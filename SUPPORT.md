# Support

finbrief is pre-release. There is **no support SLA at this stage** — the
maintainer engages as capacity allows.

## Where to get help

| Type of question | Where |
|---|---|
| "How do I …?" once releases exist | Documentation (`docs/`) first, then [GitHub Discussions](https://github.com/Siddhesh-ai-del/finbrief/discussions) |
| Bug reports | [GitHub Issues](https://github.com/Siddhesh-ai-del/finbrief/issues) using the Bug report template |
| Feature ideas | [GitHub Issues](https://github.com/Siddhesh-ai-del/finbrief/issues) using the Feature request template |
| Security vulnerabilities | [Private security advisory](https://github.com/Siddhesh-ai-del/finbrief/security/advisories/new) — never a public issue (see [SECURITY.md](SECURITY.md)) |
| Conduct concerns | Private contact per [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Before you ask

1. Read [README.md](README.md) — especially **Project status**. Almost
   everything is still planned; the answer to "how do I install it?" is
   currently *not yet available*.
2. Search [existing issues](https://github.com/Siddhesh-ai-del/finbrief/issues).
3. Check [CHANGELOG.md](CHANGELOG.md) for what has actually changed.

## Commercial support

Not offered. If the project reaches a released, supported state, this section
will describe support tiers honestly — no tiers will be advertised before
they exist.
